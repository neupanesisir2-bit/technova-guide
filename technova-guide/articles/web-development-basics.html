How websites work: HTML, CSS and JavaScript explained

Beginner guide · 7 min read · TechNova Guide

A website is delivered by a web server and displayed by a browser. The browser requests resources such as HTML, CSS, JavaScript, images and fonts, then combines them to render a page. These three core technologies each have a different job.

HTML: structure and meaning

HTML describes the content and structure of a page. Headings, paragraphs, navigation, links, images and forms are represented with elements. Semantic HTML helps browsers, search engines and assistive technologies understand the page.

<main>
  <h1>Welcome to my website</h1>
  <p>This is my first page.</p>
</main>

CSS: layout and appearance

CSS controls presentation: colors, spacing, typography, responsive layouts, borders and animations. A well-structured page can adapt to narrow phone screens and wide desktop displays.

body {
  font-family: system-ui, sans-serif;
  line-height: 1.6;
  margin: 2rem;
}

h1 { color: #3157a4; }

JavaScript: behaviour

JavaScript makes a page interactive. It can respond to clicks, validate forms, filter content and update the page without a full reload. Keep interactions understandable and provide keyboard support.

const button = document.querySelector("#hello");
button?.addEventListener("click", () => {
  alert("Hello from JavaScript!");
});

What happens when someone opens a website?

  1. The browser resolves the domain name using DNS.
  2. It connects to the server, typically using HTTPS.
  3. The server returns the requested page and related resources.
  4. The browser parses HTML, applies CSS and runs JavaScript.
  5. The browser displays the page and may fetch additional resources.

Build your first project

Create a folder with an index.html, a style.css and a script.js. Start with a page about a topic you know. Add a heading, a short explanation, a navigation link and one small interactive feature. Test it at phone and desktop widths.

Before publishing: Use HTTPS, descriptive page titles, accessible labels, compressed images, working navigation and a privacy notice that matches the services your site actually uses.

Where to learn next

After the basics, explore responsive design, accessibility, browser developer tools, HTTP, APIs, version control with Git and deployment. Build small projects and inspect how they behave in more than one browser.

Code examples are educational starting points. Test and adapt them before using them in a production website.
